# Trade one — Pharma Catalyst Feed

Vite + React + TypeScript app for a dark clinical-editorial pharma catalyst feed (Feed / Calendar / Glossary). Seeded from the Trade one briefing of ~14 Nov 2026.

**Not financial advice.**

## Run locally

```bash
cd apps/trade-one
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React 19 + TypeScript
- Seeded catalysts, calendar, and glossary in `src/data/`
- Styles match the approved HTML prototype (Instrument Serif / DM Sans / JetBrains Mono)
